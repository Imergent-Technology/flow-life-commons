# G6 debt register

Known issues and deferred work that G6 records rather than fixes. The policy is in the [G6 contract, §12](README.md#12-deferred-issues-and-the-debt-register): the register outlives G6, G7's design gate must read it, and each later milestone's design gate checks its triggers.

**Fields:**
- **Severity** uses the G6 scale (BLOCKER, HIGH, MEDIUM, LOW, INFORMATIONAL). *Unclassified* means the classification is itself the pending work.
- **Disposition** is *fix* (in a named package), *accept* (with who accepted it), *defer* (with a trigger), or *investigate*.
- **Release impact** says whether the item affects the next production release ([next-release readiness](../../runbooks/g10-release-readiness.md)).
